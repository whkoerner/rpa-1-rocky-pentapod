## v0.2 acoustic changes

The active EXP-003 v0.2 renderer now reads the Chordic acoustic export rather than hard-coding the prior 180 Hz reference.

New reference:
- semantic baseline: 120 Hz
- semantic range at the reference baseline: about 95-151 Hz
- fallback baseline: 105 Hz
- recommended output band: 80-180 Hz

Fallback bytes remain exact, but their audible representation is now a low four-anchor base-5 contour instead of bright multi-octave CT2-style chords.

The contour timbre is shifted toward:
- stronger fundamental;
- restrained subharmonic body;
- much less second/third harmonic energy;
- subtle amplitude pulse and vibrato.

Design target: low rumble / low-register tonal bird call, not high chirps, alarm tones, or MIDI-like beeps.

## Translation sequencing change

The fixed 0.75 s English lead-in is removed.

New invariant:
1. Chordic playback is requested.
2. English translation is queued.
3. The English voice waits for the actual Chordic playback-start gate.
4. It then waits the complete deterministic Chordic WAV duration.
5. Audible English begins only after the Chordic source playback window has completed.

This is deliberately conservative and ensures the translation cannot finish before the source utterance. A future duration-aware overlap scheduler may be explored only if it preserves that invariant.
