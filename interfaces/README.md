# Interfaces

Human controls include the dependable physical translation button, voice and clap conveniences, web/phone control, optional remote, visible sensor state, physical microphone/camera disable controls, and supervised teleoperation.

## Machine interfaces

- [RPA-Link v0.1](rpa_link/README.md) — hardware-independent command and telemetry interface for the simulator, Linux computers, Raspberry Pi, and later real-time microcontrollers.
