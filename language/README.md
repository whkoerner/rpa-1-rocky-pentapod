# Musical Language

- `specification/`: normative CSP version and audio-safety limits
- `dictionary/`: human-readable vocabulary exports
- `grammar/`: grammar explanations and examples
- `audio/`: generated examples only; do not store copyrighted movie audio
- `encoder/` and `decoder/`: language-specific implementations
- `tests/`: deterministic round-trip and acoustic-recognition tests

The AI assistant may propose semantic intent, but only the versioned codec may generate literal musical tokens.
